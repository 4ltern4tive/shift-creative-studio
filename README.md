# SHIFT STUDIO®

One-page portfolio website for **SHIFT STUDIO**, an independent creative studio based in Montevideo, Uruguay.

Bilingual (English / Spanish) static site — no build step required.

## Stack

- Plain HTML, CSS and vanilla JavaScript
- Local fonts (PP Neue Montreal Medium, Inter Regular)
- No frameworks, no dependencies

## Structure

```
index.html
assets/
  css/style.css
  js/main.js
  fonts/
  img/
```

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Hosted on Cloudflare Pages — build command: *(none)*, build output directory: `/`.
